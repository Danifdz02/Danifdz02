## 🚀 Proyectos destacados

### 🛡️ [Cazatimos](https://cazatimos.com) — Verificador de estafas
Web para que cualquier persona en España compruebe si un enlace, SMS o número de teléfono es un posible timo o phishing, antes de caer en él.
- Verificación de **URLs**, **mensajes SMS** y **números de teléfono**.
- Base de datos colaborativa de **reportes de estafas** enviados por los usuarios.
- Frontend en **React**, desplegado en hosting con **cPanel** y dominio gestionado con **Cloudflare**.

### 💪 [EvoluFit](https://www.evolufit.es) — Plataforma de fitness
Frontend **React + Vite (PWA)** y API **Node + Express + TypeScript + Prisma** con **MySQL**.
- Catálogo de ejercicios con técnica, rutinas predefinidas y personalizadas, entrenamiento guiado y registro de progreso.
- Autenticación con roles (`normal`, `premium`, `admin`) y suscripciones **premium** con **Stripe**.
- Generador de rutinas, logros y rachas, y calculadoras interactivas (IMC, 1RM, gasto calórico).
- Mapa de zonas públicas de calistenia con equipamiento y rutina recomendada.
- Sistema de noticias gestionado desde el panel de administración.

### 📦 Gestión de almacén por kilos para cooperativas agrícolas
Control en tiempo real de entradas y salidas de producto por calibre y almacén. **Java · Spring Boot · React · SQL Server**.
- Entradas/salidas de stock con reparto automático **FIFO** y control transaccional.
- Escaneo de partidas con pistola de código de barras y generación de etiquetas **PDF** (iText).
- Autenticación **JWT** en cookie HttpOnly, con roles por nivel y por almacén.
- Inventario y **trazabilidad completa** de cada partida (origen y consumo).
- Panel de administración con gestión de usuarios y auditoría de accesos y movimientos.
- Monitorización de datos de maquinaria en tiempo real con **Grafana** sobre **MySQL**.

### 🖥️ Terminales ligeros con Raspberry Pi
Sustitución de equipos antiguos (Windows XP/7) por **Raspberry Pi 4** que dan acceso a una máquina virtual por **RDP**.
- Imagen maestra sobre **Raspberry Pi OS (Debian Trixie)** con escritorio **Wayland/labwc**, arranque directo al escritorio remoto (Remmina) y modo monopuesto.
- Barras de estado personalizadas con **waybar** (equipo, red, IP, señal Wi-Fi) y splash de arranque propio.
- **Panel de control propio en Python + GTK**, protegido por contraseña: Wi-Fi, red (DHCP/IP manual vía NetworkManager), escritorios remotos, VPN PPTP y reinicio.
- Administración remota por SSH/VNC y scripts de automatización para el despliegue.

### 🎈 VegaPark — Web para parque infantil (encargo)
Web para un parque de bolas y cumpleaños en Almería.
- **Reservas online** con **pago de señal**.
- **Panel de administración** para gestionar reservas y contenido.
